# E-Commerce Purchase Data Analysis using Pandas

## Overview

This project performs Exploratory Data Analysis (EDA) on an e-commerce purchase dataset using Python and Pandas.

The objective is to extract useful insights from customer purchase data by applying data cleaning, filtering, aggregation, and string manipulation techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## Analysis Performed

### Data Exploration

* Displayed top 10 rows of the dataset
* Displayed last 10 rows of the dataset
* Checked data types of all columns
* Identified missing values
* Determined dataset dimensions (rows and columns)

### Purchase Analysis

* Highest purchase price
* Lowest purchase price
* Average purchase price

### Customer Analysis

* Count of users with French (fr) language
* Count of users whose job title contains "Engineer"
* Purchase distribution between AM and PM

### Credit Card Analysis

* Count of Mastercard users with purchases above 50
* Email lookup using credit card number
* Count of credit cards expiring in 2020

### Email Analysis

* Extracted email providers from email addresses
* Identified top 5 most popular email providers

## Key Pandas Concepts Used

* value_counts()
* Aggregation Functions
